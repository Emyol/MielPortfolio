# Replace Silver Field with Dive

The owner approved the "Dive" prototype on 2026-11-18 (published privately; history in `current-state.md`) and asked for it to be implemented. Dive supersedes ADR-0001 and ADR-0002: the ASCII portrait and the Liquid Field leave the home page, and the glyph material becomes one ocean canvas behind the whole page with a whale shark, scroll scenes and liquid-glass panels.

How it is built: `components/dive/Dive.jsx` renders the whole page on the server from the editable content, so it reads without JavaScript and stays crawlable. `components/dive/DiveRoot.jsx` runs `components/dive/engine.js` after hydration, a dependency-free port of the prototype script that returns a cleanup removing every listener, timer and animation frame. Styles live in `app/dive.css`, scoped under `.dive` so `/admin` is untouched. GSAP, lenis and Framer Motion are not used by the new page.

Details the content model does not hold yet (each project's facts, stack, window title and interactive piece; which project proves each discipline) live in `lib/dive/extras.js`. Adding them to `seed.json` directly would make stored Supabase content fail validation, so they move into the model only together with an upgrade step for stored content.

Section names on the page (Work, Experience, Recognition, About, Contact) are fixed by the design; the navigation content still decides which sections appear.
