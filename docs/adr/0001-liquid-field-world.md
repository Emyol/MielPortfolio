# Liquid Field replaces Operator Console

The Surface is a Craft Showcase: Visitors remember the interface first. Operator Console (terminal chrome, box-drawing, prompt copy, stacked CRT effects) was a costume. We replace it with **Liquid Field**: Canvas UI Liquid as Signature Material in the first viewport only, **Silver Field** ink (near-black, white/silver fluid, no second hue), and **Signature Type** as the second identity (Fraunces + Public Sans, pin-and-typeset on section titles). We rejected an editorial-only World, a cartographic instrument, a cabinet of rare UI tricks, whole-page Liquid, and rainbow fluid. Work, leadership, metrics, CV, and contact stay. Work and contact may use shadcn Button/Card restyled to Silver Field; they must not read as Nova. GSAP may drive pin-and-typeset; it may not become a third GPU identity. Operator Console residue is deleted, not kept as texture.
